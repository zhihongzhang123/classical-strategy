# 古典谋略 × 真实交易执行

把《孙子兵法》《三十六计》《道德经》《资治通鉴》读进投资交易里。这个库分两层：

- **心法（xinfa/，8 篇）** — 跨书蒸馏出的八条交易心法，每条是一个完整的因果模型，直接对应一个可执行的操作问题（怎么打、怎么等、怎么败、怎么退出）。
- **四书逐篇解读（sunzi-bingfa/ · sanshi-liuji/ · daodejing/ · zizhi-tongjian/，35 篇）** — 四本书每一篇/每一套/每个主题的深入解读，逐字对原文、落到市场机制、给出失效边界。

**说不出失效边界的解读是鸡汤，不配进这个仓库。** 这是全库唯一的准入标准，由 CI 强制执行（`scripts/validate-content.py`）。

阅读顺序：

```
先学不败：01 先胜后战 → 04 善败
再学等待：02 庙算 → 03 以逸待劳
然后学退出：05 知足不辱
最后学格局：06 守正出奇 → 07 反者道之动 → 08 知彼知己
```

前四篇管「怎么不死」，后四篇管「怎么活得久且值得」。这个顺序本身就是心法：**生存优先于收益，下限优先于上限。**

## 与同类内容库的区别

这个仓库的前身是一个 35 篇的古典谋略解读库。2026-09 的审计发现了它的三个结构性问题，然后推倒重来：

1. **21/35 篇含「[待补充]」占位符**——一句话精髓、行动指南、案例全是模板空壳
2. **同一段案例被脚本批量复制进全部 35 篇**——「巴菲特买可口可乐」同时出现在《谋攻篇》《胜战计》《知足不辱》《盛衰周期》里，与章节内容零关联
3. **验证脚本只查章节标题存在性**——空壳内容全绿通过 CI

## 贡献

```bash
# 新增一篇心法
cp templates/xinfa-template.md xinfa/09-<name>.md
# 或新增一篇四书解读
cp templates/book-chapter-template.md sunzi-bingfa/14-<name>.md
# 按模板写完全部内容（必需节一个不能少，写完删掉「写作纪律」节）
python3 scripts/validate-content.py   # 本地先过全部五类内容
git push                              # CI 会再跑一次
```

写之前读模板里的写作纪律。**真实案例只能用公认的市场史事件，禁止编造，禁止引用无法核实的故事。** 市场映射要落到因果机制（什么条件→什么路径→什么结果），不是「此计对应炒股要谨慎」式的贴标签。

## 风险声明

- 本库是思维方法与历史案例的整理，不构成任何投资建议
- 「心法」与「解读」描述的是决策纪律的因果结构，不保证任何收益
- 所有失效边界请当作正文读，不是免责声明——**一条原理什么时候失灵，和它什么时候有效同样重要**
- 三十六计部分立场是「识破操纵」而非「教人操纵」；任何以古典智慧为名的荐股、带单都是骗局
