# 中国古典谋略经典知识库 - 投资者与散户版

专为投资者和散户打造的中国古典谋略学习平台，将古代智慧转化为投资决策力和市场生存法则。

## 🎯 为什么投资者需要学习古典谋略？

金融市场如战场，人性千年未变。《孙子兵法》教你战略配置，《三十六计》助你识别市场陷阱，《道德经》培养长期主义心态，《资治通鉴》让你看透牛熊周期。

### 核心价值
- **提升决策质量**：用千年智慧对抗情绪化交易
- **识别市场陷阱**：看穿主力套路，避免成为"韭菜"
- **构建投资体系**：从碎片化信息到系统化思维
- **穿越牛熊周期**：理解历史规律，把握大趋势

## 📚 四大经典模块 - 投资者必修

| 模块 | 篇章数 | 难度 | 投资应用场景 |
|------|--------|------|--------------|
| **三十六计** | 6 套 36 计 | ⭐⭐ | 识别市场骗局、主力操盘手法、散户自救策略 |
| **孙子兵法** | 13 篇 | ⭐⭐⭐⭐ | 资产配置、风险控制、仓位管理、投资策略 |
| **道德经** | 8 主题 | ⭐⭐⭐⭐⭐ | 投资心态、长期主义、价值投资哲学 |
| **资治通鉴** | 8 主题 | ⭐⭐⭐⭐ | 历史周期、政策研判、行业兴衰、人性洞察 |

### 🎓 散户学习路径（建议 8 周完成）

```
第 1-2 周：防身术入门
└─ 三十六计 → 识别"杀猪盘"、"割韭菜"套路，保护本金

第 3-4 周：构建投资框架
└─ 孙子兵法 → "先胜后战"思想，建立交易系统

第 5-6 周：修炼投资心态
└─ 道德经 → "无为而治"，克服贪婪恐惧，坚持长期主义

第 7-8 周：看透历史周期
└─ 资治通鉴 → 理解牛熊转换，把握时代机遇
```
