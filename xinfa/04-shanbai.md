# 心法四：善败 — 止损不是失败，是市场超出了你的框架

> 古典锚：《孙子·谋攻篇》「小敌之坚，大敌之擒也」；《史记》「善败者不亡」

## 核心命题

败是必然事件，败得起才是能力。**止损不是认错，是承认「市场走出了我框架之外的东西」——然后用最小代价退出，把资本和判断力留给下一场。** 死扛的每一步都在把一次小败养成一次出局。

## 因果机制

「小敌之坚，大敌之擒」的机制链：

- 你的仓位相对市场结构永远是「小敌」——没有任何力量能阻止价格按它自己的逻辑走
- 「坚」= 拒绝承认框架失效：浮亏触发损失厌恶（痛苦是同等盈利快乐的 2-2.5 倍）→「不卖就没亏」→ 拒绝实现损失
- 市场不理会你的成本价。死扛 = 把定价权从你的框架移交给你的痛苦——**小亏拖成大亏的路径不是价格造成的，是心理造成的**
- 「大敌之擒」：最终在最大痛苦点被迫交出仓位（强平、割在地板）——被市场俘虏

善败的工程化只有一条：**败的代价在建仓前就定死**（止损位 = 框架失效的可观测边界），败发生时只执行、不辩论。损失有界 → 可以败 N 次 → N 次里必然覆盖到胜。真正被消灭的从来不是败过的人，是败一次就出局的人。

更深一层：**败是数据**。每笔止损都精确定位了框架的一个失效边界——把败翻译成可结算的证伪记录（哪个假设、在什么状态下、被什么价格证伪），败得越多，框架的边界越清楚。「善败者不亡」不亡的不是运气，是这个学习回路。

## 执行样本（市场层数据）

我们引擎的每一份计划文件，thesis 里都强制含一段失效条件，建仓那一刻写完：「收盘跌回结构位下方即突破证伪、论点作废」。败的定义先于入场存在，触发即执行，盘中无临场裁量。

另一个样本是系统层面的败：一次通道迁移事故导致下单被拒，引擎误读权益状态、误报全额亏损熔断。处置三步——立即停机（不带着错误状态继续交易）、根因留痕（写清是误报不是真亏损）、修复授权后才恢复。**善败的对象包括自己的系统：系统层面的败同样要快速止损 + 根因归档，不是只有价格层面的败才叫败。**

## 识别条件

善败是否在执行，四查：

1. 败的定义先于入场存在吗？（止损位 + 触发条件在建仓前写下，可观测、无歧义）
2. 败的代价有界吗？（仓位 = 可亏金额 ÷ 单位亏损额；单次败 ≤ 预设上限）
3. 触发时执行的是动作还是辩论？（执行 = 善败；「再等等看」= 小敌之坚的开始）
4. 败被翻译成数据了吗？（错误归因四类：归因错 / 时机错 / 模型错 / 盲区——不同类型的败，修的东西完全不同）

## 失效条件（这条心法自己什么时候失灵）

- **止损位选错 = 慢性失血**：止损设在噪音区（成交密集支撑位）会被反复扫损，「善败」退化为「频繁小败」，累积成本吞掉盈亏比。判据：同一结构连续 3 次被扫损 = 止损逻辑错了，修逻辑，不是放宽止损
- **系统性事件里止损执行不了**：熔断级流动性蒸发时，止损单以跳空价成交甚至无法成交——「败有界」的前提是市场连续。极端缺口是善败的物理边界，只能靠仓位预先缩小，不能靠止损单事后兜底
- **当你把败的定义权交出去，善败就不成立**：杠杆与保证金结构下，强平点由券商定不由你定——2015 年配资盘的止损不由配资者执行。这是「只用亏光不心疼的钱」的深层原因
- **善败不能替代选仗**：败得起 ≠ 值得打。「反正有止损」当入场理由，是用善败给无算背书——顺序永远是先胜后战在前，善败在后

## 历史验证（含失败案例）

- 成：2020 年困境反转类交易模板——止损明确到具体价位，跌破即走；盈亏比极高的前提是败完全有界
- 成：2026 年 9 月的系统误报事故——快速停机 + 根因留痕 + 修复恢复，基建事故没有升级为资金事故
- 败（边界）：2015 年 A 股场外配资——不是没有止损意愿，是 1:5 杠杆下止损点不归你管。千股跌停里想败都败不掉，这是「败的定义权」条款的血证

## 常见误用

1. **止损 = 预测「会跌」**：止损触发不证明看空，只证明这一个框架失效。止损后价格涨回去不叫止损错了，叫这笔买卖本来就不属于你——用结果评价决策质量是校准的头号敌人
2. **移动止损变移动借口**：价格逼近止损时「再给它一点空间」——每一次放宽都在训练小敌之坚。唯一合法的调整方向：向盈利侧移动（锁盈），永不向亏损侧移动
3. **败后不分类**：把时机错（方向对时间错）当模型错（因果错）处理 = 砍掉好模型；把归因错（方向对原因错）当胜 = 毒药留在框架里。善败的下半场是归因，不归因的败白败
