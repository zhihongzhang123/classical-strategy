# 孙子兵法·地形篇 — 核心思想

## 一句话精髓

**选对战场，赢一半。选错战场，输全部。**

## 核心思想

### 六种地形

- 通形（四通八达）：先占据高地
- 挂形（易进难退）：可以进但要确保能退
- 支形（双方对峙）：不要先动，引诱对手先动
- 隘形（狭窄通道）：先占据就堵住，后到就别打
- 险形（险要地势）：先占据就守住，后到就撤退
- 远形（距离远）：势均力敌时不要主动挑战

核心逻辑：同样的兵力，在不同地形上战斗力天差地别。选择战场比战斗本身更重要。

### 失败的责任永远在领导者

六种导致失败的情况，全部是将领的错：
1. 势均力敌却以一击十
2. 士兵强但将领弱，管不住
3. 将领强但士兵弱，带不动
4. 偏将不服主将，各自为战
5. 将领无威信，军队混乱
6. 将领不会判断，以弱击强

### 四维信息完整才能确保胜利

了解对手和自己，不会输。了解天时和地利，才能完全赢。

光知道敌我双方不够，还要知道环境因素。四维信息（彼、己、天、地）完整，才能确保完全胜利。

## 现代案例

### 商业中的地形

- 通形 = 开放市场 → 先建立品牌壁垒
- 挂形 = 容易进入难退出 → 谨慎进入
- 支形 = 红海市场 → 不先降价
- 隘形 = 细分垄断 → 先占据就守住
- 险形 = 高门槛行业 → 先进入者有绝对优势

### 交易中的地形

- 通形 = 震荡区间 → 先占据关键位
- 挂形 = 追涨行情 → 设好止损再进
- 支形 = 多空僵持 → 等突破信号
- 隘形 = 关键支撑/阻力位 → 先占据就守住
