# 孙子兵法·行军篇 — 核心思想

## 一句话精髓

**观察力决定生存力。从细节中读懂对手和环境，比任何战略都重要。**

## 核心思想

### 因地制宜

不同环境需要不同策略。没有"万能方案"，只有"因地制宜"。

- 山地：靠近山谷扎营，居高临下
- 水地：远离河流扎营
- 盐碱地：快速通过，不要停留
- 平地：选择平坦处，背靠高地

### 从细节读懂敌情

孙子列出了大量战场观察信号：

- 树木摇动 → 敌军来了
- 鸟群惊飞 → 下面有伏兵
- 尘土高而尖 → 战车来了
- 敌人说话谦卑但加紧备战 → 要进攻了
- 敌人说话强硬但战车后退 → 要撤退了
- 敌人见利不取 → 累了
- 鸟群聚集在敌营 → 空营，人已走
- 军官易怒 → 全军疲惫

核心逻辑：高明的将领不需要特殊情报，只需要一双敏锐的眼睛。

### 先建立信任，再执行纪律

士兵还没亲近依附你就惩罚他，他不服。士兵已经亲近依附你但不执行惩罚，也不能用。

管理两个阶段：
1. 先建立信任 — 没有信任，任何规则都没用
2. 再执行纪律 — 有了信任但不执行纪律，团队就散了

顺序不能反。先恩后威。

## 现代案例

### 市场观察力

- 量能突然放大 → 有大资金进场
- 资金费率极端负值 → 空头拥挤，可能反弹
- 价格横盘但量能萎缩 → 在积蓄力量
- 大单频繁撤单 → 在制造假象
- 社交媒体突然一致看多 → 可能见顶

市场每天都在给你发信号，关键是你有没有观察力。
