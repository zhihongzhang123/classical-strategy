# 孙子兵法·九变篇 — 核心思想

## 一句话精髓

**真正的智慧不是遵守规则，而是知道什么时候该打破规则。**

## 核心思想

### 五种"不做"

- 有些路不走（可能有埋伏）
- 有些军队不打（可能是诱饵）
- 有些城池不攻（代价太大）
- 有些地方不争（不是战略要地）
- 有些命令不执行（情况变了）

智慧不在于"能做什么"，而在于"不做什么"。克制比行动更难，也更重要。

### 同时看到利和害

聪明的人考虑问题，一定同时看到利和害。

- 只看到利 → 盲目乐观 → 忽视风险 → 失败
- 只看到害 → 过度悲观 → 错失机会 → 失败
- 同时看到 → 理性决策 → 趋利避害 → 成功

### 任何优点走向极端都是致命弱点

将领有五种致命弱点：
1. 勇敢 → 不怕死 → 被诱杀
2. 谨慎 → 贪生 → 被俘虏
3. 正义感 → 急躁 → 被激怒
4. 廉洁 → 好面子 → 被羞辱
5. 仁爱 → 心软 → 被烦扰

没有绝对的优点。任何品质在特定情境下都可能变成致命弱点。

## 现代案例

### 投资中的有所不为

- 有些交易信号看起来好，但不做（不符合系统）
- 有些行情看起来能赚，但不追（风险收益比不对）
- 市场情绪高涨所有人都在喊买入，你不跟

好的交易者不是"什么机会都抓"，而是"知道什么机会不抓"。

### 五危在投资中的映射

- 不怕死 → 满仓杠杆，被一波带走
- 贪生 → 极度保守，永远赚不到钱
- 急躁 → 被止损后报复性交易
- 好面子 → 不肯认错，死扛浮亏
- 心软 → 太在意别人看法，被噪音干扰

## 行动指南

1. 你现在做的事在"有所不为"清单上吗？
2. 你的优点有没有走向极端？
3. 你同时看到了利和害吗？
