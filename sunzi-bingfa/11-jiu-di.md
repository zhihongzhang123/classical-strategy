# 孙子兵法·九地篇 — 核心思想

## 一句话精髓

**人在不同处境下的心理状态完全不同。高明的领导者懂得利用环境来塑造行为。**

## 核心思想

### 九种处境

- 散地（家门口）：想回家不想打 → 快速通过
- 轻地（刚入敌境）：容易退 → 不要停，继续深入
- 争地（必争之地）：谁先到谁赢 → 抢先占据
- 交地（交通便利）：容易被切断 → 保持联络
- 衢地（多国交界）：需要外交 → 结交盟友
- 重地（深入敌境）：无路可退 → 就地取粮持续进攻
- 圮地（险恶环境）：环境恶劣 → 快速通过
- 围地（入口窄出口远）：容易被围 → 用计谋突围
- 死地（无路可退）：不拼命就死 → 激发死战决心

### 绝境反而能激发战斗力

把军队投入绝境，反而能生存。

为什么？
- 人在有退路时，会犹豫、会退缩、会保留
- 人在没有退路时，会爆发全部潜能

项羽"破釜沉舟"就是这个原理：烧掉船只、砸掉锅碗，士兵知道回不去了，只能拼命。

注意：这不是"主动找死"，而是在特定情况下，消除退路能激发最大战斗力。

### 集中力量朝一个方向猛攻

用兵的关键：先假装顺从对手的意图，然后集中全部力量朝一个点猛攻。力量集中到极致，可以产生不可思议的效果。

## 现代案例

### 创业中的死地

很多成功创业者都有"死地"经历：把所有积蓄投入，没有退路 → 拼命干。这种状态激发了平时不可能有的创造力。

### 交易中的九地

- 散地 = 小仓位试水 → 容易随意操作
- 重地 = 重仓持有 → 必须认真分析
- 死地 = 满仓浮亏 → 要么止损要么扛

教训：永远不要让自己进入交易的"死地"。仓位管理就是为了避免这种情况。

3. 有没有把自己逼到超出承受范围的"死地"？
