# 孙子兵法·用间篇 — 核心思想

## 一句话精髓

**情报是战略的血液。没有情报的战略是瞎子摸象。**

## 核心思想

### 五种情报来源

1. 因间：利用普通人收集基础信息
2. 内间：收买内部人员获取决策信息
3. 反间：策反对手的间谍（最重要的一种）
4. 死间：故意传递假情报欺骗对手
5. 生间：派出去能活着回来报告的

五种不是独立使用的，而是组合使用，形成完整的情报网络。

### 反间是核心

反间最重要。为什么？
- 反间是对手的间谍，他知道对手的情报网络
- 策反了反间，就能知道对手知道什么
- 通过反间，可以操控对手获得的信息
- 反间可以帮你识别和策反其他间谍

控制了反间，就控制了整个信息流。

### 情报只能从人那里获取

事先了解情况，不能靠猜测、不能靠占卜、不能靠类比推测。必须从了解敌情的人那里获取。

情报是唯一的确定性来源。其他都是概率，情报是事实。

## 现代案例

### 交易中的情报

- 因间 = 公开数据（价格、量能、资金费率）
- 内间 = 链上数据（大户持仓变化、交易所流入流出）
- 反间 = 识别市场假信号（诱多/诱空）
- 死间 = 大户故意制造的假突破
- 生间 = 你的交易系统实时反馈

不要只看价格（因间），要看链上数据（内间），要识别假信号（反间）。

## 全书总结

十三篇核心逻辑链：

始计篇：先算账 → 算清了再打
作战篇：算成本 → 打得起才打，速战速决
谋攻篇：算方式 → 最好不打就赢
军形篇：先不输 → 积累实力
兵势篇：再造势 → 用势能放大实力
虚实篇：争主动 → 调动对手，避实击虚
军争篇：争先机 → 以迂为直
九变篇：懂变通 → 有所不为
行军篇：重观察 → 从细节读懂环境
地形篇：选战场 → 环境决定战斗力
九地篇：懂心理 → 处境塑造行为
火攻篇：慎毁灭 → 情绪不做决策
用间篇：重情报 → 信息是战略基础

全书一句话：先算清楚，做好准备，选好战场，掌握主动，用最小代价取得最大胜利。能不打就不打，必须打就快打。
